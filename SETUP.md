# Abhay Current Affairs — Setup

1. Create a GitHub repository.
2. Upload this folder's contents.
3. Enable GitHub Pages from Settings → Pages → deploy from the main branch.
4. Your HTML blog will be online.
5. GitHub Actions runs daily around 06:00 IST and regenerates `data.json`.
6. Optional: add GitHub Secret `OPENAI_API_KEY` to generate original AI summaries.
7. Optional: add repository variable `OPENAI_MODEL` with a model available to your account.

For World/Economy/Science/Sports, add permitted RSS feeds or a licensed API to `sources.json`. Do not republish full copyrighted articles. Keep source links visible and verify important facts before using them for exams.
